# ctebow.github.io

Personal portfolio, built with [Jekyll](https://jekyllrb.com/) and the
[no-style-please](https://github.com/riggraz/no-style-please) theme.

```sh
bundle install
bundle exec jekyll serve --livereload   # http://localhost:4000
```

See [GUIDE.md](GUIDE.md) for how to add pages, projects, and posts.
